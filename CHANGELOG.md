# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.6.0] — 2026-11-09

Приложение обновляет само себя: спрашивает у GitHub последний релиз, скачивает нужный файл,
проверяет контрольную сумму, подменяет себя и перезапускается.

### Добавлено
- **Проверка обновлений** при запуске (можно выключить в настройках) и кнопка
  «Проверить обновления сейчас» + тумблер «Проверять обновления при запуске».
- **Скачивание прямо из релиза GitHub**: `Ludex-Setup-*.exe` или `Ludex-*-portable.exe`
  (Windows), `Ludex-*-macos-arm64.zip|dmg` / `Ludex-*-macos-x64.zip|dmg` (macOS),
  `Ludex-*-linux-x64.tar.gz|deb` (Linux). Файл берётся по текущей системе и архитектуре.
  Проверяется `sha256` из метаданных ассета, прогресс виден в окне.
- **Установка без ручных действий**: Windows — тихий запуск установщика `/S` либо замена
  портативного `.exe` (из `Program Files` — через UAC); macOS — замена `Ludex.app`
  (`ditto`, при необходимости с паролем администратора); Linux — распаковка архива и
  подмена бинарника (`pkexec`, если папка принадлежит root). После замены приложение
  запускается заново само.
- Диагностика из консоли: `Ludex --version`, `Ludex --update-check`,
  `Ludex --update-apply`. Переменная `LUDEX_UPDATE_FEED` подменяет адрес фида
  (для тестов на локальном сервере).
- Если обновиться на месте нельзя (папка только для чтения и нет `pkexec`), приложение
  честно пишет об этом и даёт ссылку на релиз, вместо тихой неудачи.

## [1.5.0] — 2026-11-09

Версии для Linux и macOS: одно и то же приложение теперь собирается под три системы.

### Добавлено
- **Linux**: `Ludex-1.5.0-linux-x64.tar.gz` (портативный архив с ярлыком и инструкцией)
  и `Ludex-1.5.0-linux-x64.deb` (`sudo apt install ./Ludex-1.5.0-linux-x64.deb` —
  кладёт `/opt/ludex`, ярлык в меню и иконку).
- **macOS**: `Ludex-1.5.0-macos-arm64.dmg` (Apple Silicon) и `Ludex-1.5.0-macos-x64.dmg`
  (Intel) — полноценный `Ludex.app` с иконкой `.icns` и `Info.plist` внутри DMG-образа:
  открыл, перетащил в `Applications`, готово. Те же сборки лежат и в `.zip`.
- Поиск игр под каждую систему: в Linux — AppImage, нативные бинарники и `.sh`-обёртки
  (библиотеки `.so` и ярлыки `.desktop` отбрасываются), в macOS — `.app`-бандлы;
  в Windows всё как раньше, `*.exe`.
- Запуск игр кроссплатформенно: в macOS `.app` открывается через `open`, в Linux
  бинарнику при необходимости ставится бит выполнения.
- `build.sh` собирает все три платформы одной командой (`./build.sh all|windows|linux|mac`),
  CI-воркфлоу собирает их матрицей и выкладывает артефакты.

### Изменено
- Кнопка «Играть от админа» и пункт контекстного меню скрываются там, где нет UAC
  (Linux/macOS); переключатель автозапуска в настройках уже был неактивен вне Windows.
- Подсказка в пустой библиотеке больше не упоминает `.exe`.
- «Открыть папку» на macOS использует `open`, в Linux — `xdg-open`.

## [1.4.0] — 2026-11-08

Переименование проекта в **Ludex** и новый облик.

### Добавлено
- Новый логотип (белый знак на чёрном квадрате): в шапке окна, иконке exe, установщике и ярлыках.
- Перенос данных со старого имени: при первом запуске `%LOCALAPPDATA%\GameVault` копируется
  в `%LOCALAPPDATA%\Ludex`, старые ярлыки и запись автозапуска удаляются.

### Изменено
- Приложение называется **Ludex** (exe — `Ludex.exe`, папка установки — `%LOCALAPPDATA%\Programs\Ludex`).
- Тёмная тема стала почти чёрной под новый логотип: фон `#08090C`, чёрная шапка, графитовые
  панели, контрастный белый текст. Светлая тема не изменилась.
- Сетка библиотеки заполняет ширину окна: ширина карточки и число колонок считаются под размер
  окна, пустого места справа больше нет, отступы между карточками увеличены до 18 px.
  При изменении размера окна сетка перестраивается.

## [1.3.5] — 2026-11-08

- Белая подложка и контур вокруг выпадающих списков и контекстного меню: панели больше не
  рисуются отдельным окном ОС, а лежат внутри окна приложения (`OverlayPanel`).

### Добавлено
- Закрытие панелей по клику мимо, по `Esc` и при изменении размера окна.
