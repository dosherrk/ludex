Ludex 1.4.0 — локальная библиотека игр (Windows 10/11, 64-бит)
====================================================================

  Ludex-Setup-1.4.0.exe  — установщик (рекомендуется). Ставится без прав
                               администратора в %LOCALAPPDATA%\Programs\Ludex,
                               создаёт ярлыки и деинсталлятор.
  app\Ludex.exe          — портативная версия: один файл, .NET ставить не нужно.

Первый запуск: шестерёнка ⚙ → «Папки с играми» → «+ Добавить папку…» → «Сохранить» →
«Сканировать». Обложки подтягиваются из каталога Steam автоматически.

Что нового в 1.4.0:
  • приложение переименовано в Ludex и получило новый логотип
    (белый знак на чёрном квадрате) — в шапке, на иконке ярлыков и в установщике;
  • тёмная тема стала по-настоящему чёрной под новый логотип: почти чёрный фон,
    чёрная шапка, графитовые панели, контрастный белый текст (светлая тема прежняя);
  • карточки заполняют ширину окна: ширина и число колонок считаются под размер окна,
    пустого места справа больше нет, отступы между карточками чуть больше (18 px);
  • переезд с прежнего имени: настройки, библиотека и кэш обложек переносятся
    автоматически из %LOCALAPPDATA%\GameVault, старые ярлыки убираются.

Подробности — в README.md.
