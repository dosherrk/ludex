Ludex 1.19.4 — локальная библиотека игр (Windows, Linux)
================================================================

ЧТО НОВОГО В 1.19.3
-------------------
+ приложение «разворачивается» из экрана загрузки: интерфейс раскрывается из центра
  с плавным масштабом и растворением — запуск выглядит как одно движение;
+ Ludex можно поддержать: кнопка DonationAlerts на сайте и в README
  (donationalerts.com/r/c04hbiu).

ЧТО БЫЛО В 1.19.2
-----------------
- сборки для macOS больше не выпускаются: остаются Windows и Linux
  (файлы для Mac убраны с сайта и из релизов).

ЧТО БЫЛО В 1.19.1
-----------------
+ вкладка «Рекомендации» теперь называется «Каталог» — название честнее;
+ строка состояния стала всплывающим уведомлением снизу: тёмная плашка с точкой
  и полоской хода работы, по центру внизу, и гаснет, когда делать нечего;
+ сообщения о событиях (игра запущена, удалена, ошибка) — такая же плашка
  в правом нижнем углу вместо блёклого текста.

ЧТО БЫЛО В 1.19.0
-----------------
+ карточка игры открывается сразу: описание, разработчик, издатель и год
  приходят вместе с каталогом, без отдельного запроса к Steam;
+ в приложении весь каталог Steam — 130 тыс. игр (собирается раз в сутки
  автоматически, скачивается готовым файлом ~5 МБ при первом запуске);
+ описания на русском или английском — тот файл, что совпадает с языком интерфейса.

  Ludex-1.19.4-linux-x64.tar.gz     — портативный архив для любого Linux x64

WINDOWS 10/11
-------------
1. Запустите Ludex-Setup-1.5.0.exe, выберите язык, «Далее».
2. Ставится в %LOCALAPPDATA%\Programs\Ludex — права администратора не нужны.
3. Файл не подписан сертификатом: если SmartScreen скажет «Windows защитила ваш
   компьютер» — «Подробнее» → «Выполнить в любом случае».
4. Портативный вариант: запускайте Ludex-1.5.0-portable.exe откуда угодно.
Данные: %LOCALAPPDATA%\Ludex. Удаление: «Параметры → Приложения → Ludex → Удалить».

LINUX (x64)
-----------
Вариант A — пакет:
    sudo apt install ./Ludex-1.5.0-linux-x64.deb     # Debian, Ubuntu, Mint, Pop!_OS
  Появится ярлык в меню, команда ludex, файлы в /opt/ludex.

Вариант B — портативный архив:
    mkdir -p ~/Applications/Ludex
    tar -xzf Ludex-1.5.0-linux-x64.tar.gz -C ~/Applications/Ludex
    ~/Applications/Ludex/Ludex
  Ярлык для меню: скопируйте ludex.desktop в ~/.local/share/applications/
  и укажите в нём полный путь к Ludex (строка Exec=).

Требования: glibc 2.31+, X11 или Wayland (через XWayland). Библиотеки интерфейса:
libX11, libXrandr, libXi, libXcursor, libXext, libXrender, libICE, libSM, libGL,
libfontconfig, libfreetype, libxkbcommon.
Данные: ~/.local/share/Ludex.

ПЕРВЫЙ ЗАПУСК (Windows и Linux)
---------------------------
1. Шестерёнка справа сверху → «Папки с играми» → «+ Добавить папку…».
2. «Сохранить» → «Сканировать». Обложки подтянутся из Steam (нужен интернет).
3. Клик по обложке — запуск игры; клик по подписи или правый клик — панель игры.
4. Настройки → «Кастомизация»: тема, акцентный цвет, прозрачность, обои.
