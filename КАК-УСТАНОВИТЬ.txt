Ludex 1.4.0 — локальная библиотека игр для Windows 10/11 (64-бит)
=====================================================================

ЧТО НОВОГО В 1.4.0
------------------
  • приложение называется Ludex, новый логотип (белый знак на чёрном квадрате);
  • тёмная тема стала по-настоящему чёрной;
  • карточки в библиотеке заполняют всю ширину окна — справа нет пустого места,
    отступы между ними чуть больше;
  • прежние настройки и обложки переносятся автоматически при первом запуске.

ЧТО В АРХИВЕ
-----------
  Ludex-Setup-1.4.0.exe   — установщик (рекомендуется)
  portable\Ludex.exe      — портативная версия, работает без установки
  src\, installer\, assets\   — исходники, скрипт установщика, иконки
  screenshots\                — скриншоты
  README.md                   — подробное описание

УСТАНОВКА
---------
1. Запустите Ludex-Setup-1.4.0.exe
2. Выберите язык (русский/английский) → «Далее» → «Установить».
   Программа ставится в %LOCALAPPDATA%\Programs\Ludex — права
   администратора (UAC) не требуются.
3. Ярлык появится на рабочем столе и в меню «Пуск».

УДАЛЕНИЕ
--------
«Параметры → Приложения → Установленные приложения → Ludex → Удалить»
или ярлык «Удалить Ludex» в меню «Пуск».
Установщик спросит, стирать ли настройки и кэш обложек.
Файлы самих игр не удаляются никогда.

ПЕРВЫЙ ЗАПУСК
-------------
1. Шестерёнка ⚙ справа сверху → «+ Добавить папку…» → укажите папку с играми
   (можно целый диск, например D:\Games).
2. «Сохранить» → «Сканировать». Обложки подтянутся из каталога Steam
   автоматически (нужен интернет).
3. Клик по обложке — запуск игры, клик по названию — панель игры.
4. Настройки → «Кастомизация»: тема, цвет (маркер по квадрату, полоса оттенков
   или значения R/G/B), прозрачный интерфейс, обои на фон по ссылке
   (картинка, GIF или ссылка с Pinterest).

ЕСЛИ SMARTSCREEN РУГАЕТСЯ
-------------------------
Файл не подписан сертификатом: «Подробнее» → «Выполнить в любом случае».
